## 자아란 무엇일까.(이 책을 읽고..) 

10년 전의 '나'와 지금의 '나'는 같은 사람이라고 할 수 있을까?
우리 몸에서 가장 느리게 변하는 조직 중 하나인 **뼈(골격)**도 10년이면 완전히 새 조직으로 교체된다고 한다.
생물학적 관점에서만 본다면 10년 전의 나를 구성했던 '물질'과 지금의 나를 구성하는 '물질'은 다르다. 
결혼을 하면서 10년 전의 나와는 생각도 많이 달라졌다. 주변 환경이 변하면서 나의 정신세계도 그때와는 완전히 달라진 것이다.
신체적으로나 정신적으로나 10년전의 '나'와 지금의 '나'를 같다고 볼 근거는 없다.
그럼에도 10년전의 나와 지금의 나를 하나로 이어주는 것은 뭘까?
'기억'이다. 

그런데 기억은 완전하지 않다. 인스타그램에 내 삶의 전부가 아닌 하이라이트를 업로드 하듯이. 우리의 뇌도 중요한 내용만 저장한다. 
우리의 기억은 지난 삶의 전체가 아니라, 일종의 '하이라이트 릴'이다. 그리고 우리의 자아는 곧 기억이다.

```
자아는 수많은 사건 중에서 특정한 부분을 편집하고 맥락을 이어붙인 기억의 집합이다. 즉, 내가 나와 세상에 들려주는 '나에 대한 편집된 이야기'이며
우리는 무수히 많은 자아를 가진 채 살아간다.
『나라는 착각』 p.8
```

## 1장 우리는 시뮬레이션이다.

내가 생각하는 '나'는 사실 뇌의 시물레이션이다.

```
우리 대부분은 머릿속에서 들리는 목소리를 실제 목소리로 생각하고, 거울 속의 얼골이 사실 그대로 내 모습인 줄로 알고 살아간다.
이처럼 우리 각자는 우리 머릿속에서만 살고 있는 자신의 모습을 그리고 있다. 내가 선호하는 방식으로 표현하자면,
이 모습은 되가 당신의 모습과 목소리에 대해 시뮬레이션을 실행한 결과물이다.
『나라는 착각』 p.33
```

```
기억은 끊임없이 변한다. 우리가 친구, 가족과 함께 과거에 대해 추억하기 위해 모인다면, 이는 시각장애인이 시각 장애인을 인도하는 것과 같다.
『나라는 착각』 p.33
```

```
인간은 누구나 기억 속에 빈 곳이 있다면 동원할 수 있는 모든 내부적, 외부적 근원을 사용하여 이를 메우려 한다. 이는 본능이다.
신경학자들은 이런 기억 메꾸기를 작화증(confabulation)이라고 부른다.
『나라는 착각』 p.36
```

## 2장 최초의 기억들

```
약 4세에서 10대 초반에 이루어지는 발달상의 중요한 시기에는 기억과 그것을 재생하는데 참여하는 시스템 사이에
뇌의 발달 차이에 따른 상대적인 단절이 존재한다. 이 시기로부터의 기억을 회상하는 성인의 뇌는 기억을 암호화한 청소년기의 뇌와는 물리적으로 다르다.
이는 마치 VHS 테이프 기술로 녹화된 영화를 4K 해상도 장치로 관람하는 것과 같다.
『나라는 착각』 p.50
```

## 3장 뇌는 불완전한 편집자

고정관념, 확증편향은 피할 수 없다. '무서운 개'라는 스키마가 강하게 있는 사람은 반기며 다가오는 개도 무서워한다.
우리 뇌는 새로운 정보를 기존에 가진 '틀'에 끼워 맞추려는 경향이 있다.
더 나아가서 그 틀과 반대되는 정보가 들어오면 그걸 내 입맛대로 수정하거나 무시해버린다.(불편하니까)

결국 우리는 세상을 있는 그대로 보는 게 아니라, 우리가 이미 만들어 놓은 '안경(스키마)'을 통해서 보고 있는 셈이다.


```
안타깝게도, 뇌는 불완전한 편집자이다. 우리의 기억은 기껏해야 일어난 사건의 압축 버전일 뿐이다. 실제 사건을 재구성하기 위해 
뇌는 모형, 즉 사진을 나열하는 일종의 스토리보드가 있어야한다. 
『나라는 착각』 p.60
```

```
컴퓨터 과학의 세계에서는 이러한 틀을 기저함수(basis function)이라고 부른다.
예를 들어 원은 x와 y좌표를 사용하여 x^2 + y^2 radidus^2 라는 기저함수로 표현할 수 있다.
『나라는 착각』 p.60
```

```
뇌에는 원본 형태의 모든 에피소드 메모리를 저장할 만큼의 공간이 없다.
뇌는 기저함수를 사용하여 메모리의 압축된 표현을 저장한다. 심리학자들은 이러한 압축된 표현을 스키마라고 부른다.

스키마는 기존의 정보를 회상하고 새로운 사건을 인코딩하는데 영향을 준다. <중략>
스키마가 한번 형성되면, 우리 뇌는 그 이후로 볻고 듣게되는 정보를 스키마와 일치하도록 편향시킨다.
『나라는 착각』 p.70~71
```

```
스키마의 장점은 효율성에 있다. 스키마가 한 번 만들어지면, 새로운 사건은 그 스키마의 편차에 따라 처리되고 저장된다.
『나라는 착각』 p.70~71
```

```
성인에 이르면 당신의 뇌는 스키마로 가득찬다. <중략>
대부분의 스키마는 우리가 세상을 이해하는데 도움을 주는 긍정적인 역할을 한다. 또한 스키마는 무작위로 보일 수 있는 사건들에 대해
이해의 틀을 제공한다.
『나라는 착각』 p.70~71
```

## 4장 추측하는 뇌

```
'당산의 현재'는 주변에서 일어나는 일들을 내부적인 표상으로 변환하는 일종의 알고리즘이다.
『나라는 착각』 p.74
```

```
헬름 홀츠의 주장에 따르면, 눈으로부터 들어오는 정보가 보고 있는 것을 결정하지 않는다.
대신 뇌는 역문제를 풀어야한다. 즉, "망막에 닿는 광자의 흐름이 주어졌을때, 가장 가능성있는 근원은 무엇인가?"
에 답하는 것이 뇌의 인식 과정이다.
『나라는 착각』 p.77~78
```

```
이를 승자 독식(winner take all)이라고 부르는데,
우리가 사물을 볼 때, 다른 것보다 약간이라도 가능성이 더 높다면 가장 가능성이 높은 인식을 따른다는 것을 의미한다.
『나라는 착각』 p.82
```

```
시각 피질의 뉴런 활동을 추적한 다양한 동물 실험 결과,<중략>
이미지가 불확실할수록, 뉴런의 반응이 더 다양해졌다. <중략> 입력이 모호할수록 뉴런은 더 많은 가능성을 고려하는 것으로 보였다.
『나라는 착각』 p.82
```

```
산본과 체터는 인간의 뇌가 베이지안 샘플러라고 설명한다. 쉽게 말해 우리 뇌는 각각의 인식 판단에 몇가지 확률만 고려하여 판단한다.
『나라는 착각』 p.83
```


```
두 사람이 같은 일련의 사건을 목격하거나 같은 자료를 읽고도 완전히 다른 결론에 이를 수 있다. 
우리는 저마다 자신의 경험과 확률 추정에 따라 감각 자극을 해석한다.

『나라는 착각』 p.84
```



## 5장 자아를 찾아서

```
생명체에게도 첫 번째이자 가장 기본적인 과제는 나란 존재가 세계에 무엇을 하는지와
세계가 나란 존재에게 무엇을 하는지를 구별하는 것이다.

어떤 이들은 이를 '최소힌의 자아'라고 부르는데, 이는 움직임이 나에의해 수행되며, 경험이 내 것이라는 느낌이다.

『나라는 착각』 p.98
```


```
모든 동물이 최소한의 자아감을 가지고 있지만, 이야기와 언어를 사용할 수 있는 인간만이 '서사적 자아'를 갖고있다.

『나라는 착각』 p.100
```

## 8장 최초의 이야기

```
우리가 보고들은 서사는 과거 현재 미래의 자아를 연결하는 모형으로 작동한다.
우리가 인류 역사에서 유일하다고 믿는 우리 자신의 이야기는 사실 몇가지 매우 흔한 서사의 변주에 불과하다.
『나라는 착각』 p.162
```

## 9장 진화는 개인주의를 싫어한다.

```
타인의 사고를 유추할 수 있는 능력은 오직 인간만이 갖고있다. 이 능력은 우리가 다른 사람의 아이디어를 자신의 것으로 흡수하는데 도움을 준다.
연구자들은 이를 정신 이론(Theory of Mind)이라고 부르는데 간단히 ToM이라고도 쓴다. ToM은 협력을 가능케하는 강력한 진화적 적응이다.
그러나 그 떄문에 개인의 생각이 집단에 편입되어 다른 구성원에게 재분배되는 현상이 발생한다. 쉽게 말해, 우리의 뇌는 다른 사람들의 의견에 쉽게 물들도록
진화했다.
『나라는 착각』 p.167
```

```
사회에서 살아가는 이점은 개성을 잃는 대가로 얻어진다. 멘탈라이징과 ToM은 강력한 인지 기능이며, 인간의 뇌 구조에 매우 밀접하게 엮여서 어떤 생각도
정말로 당신만의 것은 없다고 할 수 있다. 협력이라는 선택의 순간을 맞을 때마다, 당신은 자신의 생각과 당신이 생각하기에 다른 사람이 생각하고 있는 것 사이를 
계속 왔다 갔다 해야한다. 멘탈라이징은 여기서 한단계 더 나아가서, 그들이 당신에 대해 어떻게 생각하는지를 시뮬레이션하는 지점까지 갈 수 있다.
즉 당신에 대해 생각하는 누군가에 대해서 생가가한다.
『나라는 착각』 p.180
```

## 10장 나의 선택이라는 착각

```
4살 정도가 되면 다른 사람들이 자신의 생각을 읽을 수 없다는 것을 깨닫는다. 성인은 자신의 내부와 외부 세계 사이의 구분을 당연하게 여기지만,
아이들에게 내면의 발견은 혁명이다. 자신의 생각이 자신의 것이라는 인식은 자아를 형성하는데 중요한 이정표가된다.
『나라는 착각』 p.182
```

```
피실험자들은 자유의지를 갖고 있다고 믿었지만, 충분한 사회적 압력이 가해지면 대부분은 혼자 반대편에 서는 두려움에 굴복했다.
『나라는 착각』 p.185
```

## 13장 뇌를 절반만 가진 남자

```
이제 우리는 불안한 결론에 직면하게 되었다. 바로 어떤 생각도 정말로 우리 자신의 것이 아니라는 결론말이다.
우리 자신의 기억조차 의심스럽다. 그것들은 하이라이트 릴이며. 그래서 우리는 빈 구멍을 메우기 위해 다른 사람이나 매체로부터 보고 듣고 읽은 것을 활용한다.
그렇다면 현실은 공유된 망상일 뿐일까? 

어느정도는 그렇다. 그러나 자신의 정체성을 한데 묶어주는 유용한 망상과, 극단적인 망상 사이의 구별은 명확하지 않다.
『나라는 착각』 p.185
```
